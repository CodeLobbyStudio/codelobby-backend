# CodeLobby Backend

Backend API for **CodeLobby**, a collaborative programming platform for live coding labs and workshops.

## Responsibilities

- Accounts and authentication: all users have the same account type
- Lobbies: the creator is the **Host**; other users join as **Participants** with a code or link
- Tasks with Host-provided starter code and tests for each enabled programming language
- Submissions, results, rankings and real-time lobby events
- Integration with the isolated code-execution runner

## Planned stack

Java, Spring Boot, PostgreSQL, Spring Data JPA, Flyway, JUnit 5 and GitHub Actions. Technology decisions may evolve.

## Contributing

Manage tasks in the **CodeLobby Development** GitHub Project. Link small Issues to feature branches and submit Pull Requests for review before merging into `main`.

> Early-stage project. Setup and run instructions will be added with the first backend implementation.
